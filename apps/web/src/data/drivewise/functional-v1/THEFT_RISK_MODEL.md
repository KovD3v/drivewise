# Theft Risk Model

v1 mostra: furti osservati, anno, eventuale recovery rate, contesto territoriale e fonte.

Non mostra una probabilità di furto per modello senza un denominatore di veicoli circolanti/immatricolati omogeneo.

Futuro:
theft_rate = furti_modello_area / veicoli_modello_circolanti_area

Il Theft Risk sarà una preference metric e un insight del report; non un hard constraint di default.
