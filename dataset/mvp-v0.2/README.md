# DriveWise Dataset v0.2

Dataset mock di sviluppo focalizzato sulla Vehicle Detail Page e sul Decision Report.

Contiene 5 veicoli completi e differenziati, con difetti noti, richiami, controlli pre-acquisto, manutenzione, TCO, svalutazione, Vehicle DNA, Garage Fit, alternative e un Decision Report mock.

Nota: tutti i dati sono sintetici/mock e non vanno usati come fonte automotive di produzione.

`calibration/` contiene JSON storici del motore standalone. Sono materiale di
calibrazione non caricato dall'API e non sostituiscono dati verificati.
